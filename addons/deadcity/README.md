# 末日赫尔辛基 · 第一版

基于服务器现有官方 Helsinki3D+ 基岩版存档，Linnanmäki 为基地。无需清空地图，新增行为包与轻量资源包。客户端需接受资源包。

## 如何开始

进入服务器后处于冒险模式，使用无线电或 `/dead:menu` 打开菜单，选择开始行动。工具会放入空背包格，不覆盖已有物品；请预留 5 个空位。

- 持枪按住使用（电脑右键 / 触屏使用按钮）持续开火；释放停止。第一版使用原版物品图标，不含写实枪械模型。
- 使用弹匣工具换弹，或 `/dead:reload`；空弹匣尝试开火也会自动换弹。`/dead:fire` 是持枪单发备用命令。
- 使用医疗包恢复 10 点生命，使用声响诱饵吸引附近感染者 9 秒。
- 无线电内选择放置路障，或 `/dead:barricade`：在身后空位放三格临时围栏，18 秒后恢复为空气；每轮两次。只在空位放置，不覆盖官方建筑，重启后也会继续清理。
- 补给点旁 5 格内蹲下 3 秒搜集，单轮每处仅可领取一次。
- 任一撤离点 6 格内停留 12 秒且不冲刺；受伤或离开会打断。只要带有物资就可提前撤离，搜集三处额外奖励 40 零件。
- 20 分钟超时、死亡、断线、重启或放弃均不结算本轮物资；已购升级与已入库零件保留。
- `/dead:base` 放弃本轮返回基地；管理员 `/lintsi:visit` 在玩法启用后也会放弃本轮，不能借此带出物资。

## 规则

五档永久武器：手枪、霰弹枪、冲锋枪、突击步枪、轻机枪。升级费用依次为 90 / 180 / 320 / 550 零件。每轮补充固定弹药、2 个医疗包、3 个诱饵。逐级升级提高射速、伤害和弹容量，参数见 `pack/scripts/rules.js`。武器当前按自动使用输入持续射击，霰弹枪每发六枚散弹，实体射线受墙面遮挡。

普通感染者 24 HP、奔跑者 18 HP、尖叫者 32 HP、重甲感染者 110 HP。击杀前 20 只各给本轮物资 +1，主要收入仍来自搜集与任务。丧尸仅围绕行动玩家生成，单玩家周边目标数随时间从 5 增至 14，全局上限 48；离玩家过远和靠近基地的感染者移除。

蹲行 / 普通移动 / 冲刺的脚本视觉警戒范围分别为 7 / 18 / 28 格，要求视线无遮挡；枪声可在 58 格内引来感染者。未重新发现玩家约 5 秒后退出追击。实际走路与近战由基岩版寻路驱动；声音和诱饵接近运动是简化引导，复杂障碍并不能保证绕行。体力耗尽后减速，恢复到 48 才解除疲劳。

基地 26 格范围提供保护。关闭自然刷怪、地形破坏与 PVP，保持傍晚；世界仍是官方地图。五处补给和两个撤离点为新增游戏点位，不代表现实中的商店或救援地点。

## 开发与部署

```powershell
npm ci --prefix addons/deadcity
python addons/deadcity/tools/build_assets.py
npm run check --prefix addons/deadcity
npm test --prefix addons/deadcity
```

`tools/build_assets.py` 生成物品、实体与资源包定义；资源包引用客户端自带纹理和僵尸几何，不下载或打包外部美术素材。

将 `pack/`、`resource_pack/`、`deploy.sh` 上传到 `/tmp/deadcity-release/`，同时上传 `addons/linnanmaki/official/pack/scripts/main.js` 为 `admin-main.js`、`official/reset_world.py` 为 `reset_world.py`、`official/watch_reset.py` 为 `watch_reset.py`。服务器 root 执行 `bash /tmp/deadcity-release/deploy.sh`。该脚本正常保存停服、更新包与服务器规则，不删除世界。

玩法激活清单另存 `/opt/bedrock/official-admin/game-packs.json`。管理员全服重置恢复官方世界后，仍加载玩法包；全服重置会清除永久升级，正常重开行动不会。不要使用旧的单包安装脚本覆盖当前激活清单。

管理包通过 `scripts/gameplay.js` 显式开关切换参观 / 玩法模式，避免跨行为包动态属性隔离导致传送命令意外开启创造模式。独立官方地图安装默认 false，玩法部署脚本在服务端写 true。

## 验证与限制

- TypeScript 按 `@minecraft/server` 2.1.0 / UI 2.0.0 检查。
- 测试覆盖弹药守恒、射速、遮挡、散弹聚合、原版受伤间隔补偿、重复结算、失败不入库、升级扣款、撤离中断、保护已有背包等。
- 服务端 `DEADCITY_READY points=7 cap=48` 表示点位准备完成；控制台 `scriptevent dead:smoke check` 验证五个物品及四种实体生命、受伤与状态事件。
- 控制台 `scriptevent dead:survey check` 为维护用分批地表读取，不改方块。此操作期间会临时多加载一个区域。
- 首发读取实服 180851 个地表点，按相邻格高度差不超过一格规划七条路线（200～482 步）。发现两个初选位置位于不连通的高台，已将 c1 / e1 各移到 3 格外的连通表面。`routes.js` 保存路线，行动中白色粒子和 HUD 提供下一路标。此为地表连通检查，不替代客户端对半砖、跳跃与碰撞的实走验收。
- 未使用真人客户端完成触屏操作、资源包显示与多人战斗验收。当前不包含室内搜刮、救援队友或全市随机任务；开放的是首个城区，非全市铺满丧尸。

官方地图来源和许可见 `../linnanmaki/assets/official-bedrock-source.json` 与 `../linnanmaki/README.md`。
