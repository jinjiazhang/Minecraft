# 炸弹人 · 独立基岩版行为包

独立目录 `addons/bomber`，有自己的 manifest UUID、源码、编译产物、测试和部署脚本，不依赖 `addons/lodestone`。

## 进服直接玩

- 服务器加载此包后，启动时自动建造竞技场；玩家登录、重生会自动进入。
- 第一位玩家等待，第二位上线后倒计时 3 秒开局。
- 第三位及以后进入玻璃等候区，有空位后自动补位。
- 每局开局补给最多 4 组（256 颗）炸弹，保留背包其他物品；空位不足时按可用格子补给。选中快捷栏 TNT，像建造放方块一样点击地面放置。/menu 可以补领炸弹。
- 引信会冒烟，最后一秒烟雾加快；爆炸时有闪光、烟雾和覆盖真实伤害范围的十字火焰粒子，连锁引爆也逐颗显示。红色标记方块与红色地板表示炸弹（背包仍用 TNT 图标），5 秒后十字爆炸；橙色地板是持续约 0.6 秒的火焰。碰到即出局，自己的炸弹也会伤到自己。
- 灰墙不可破坏，木箱会挡住爆炸并被炸掉；连锁引爆有效。
- 火焰消失后拾取金色地板（火力 +1）、绿色地板（炸弹容量 +1）。初始火力 2、容量 1，上限分别为 6、4。
- 最后存活者获胜，同时出局或 3 分钟超时为平局。
- `/menu` 或 `/bomber:menu` 查看规则。每局结束后自动弹出菜单，双方点击「重新开始」重开。
- 断线取消当前对局；重连自动加入。没有返回旧探险地图的入口。

地图为 13×11 格，每格 2×2 方块，木箱和道具对称随机。竞技场使用主世界 x=10200～10225、z=10000～10021、y=80～84；等候区 x=10228～10231、z=10000～10007。每次服务启动会重建这些预留区域并将世界出生点设为等候区。只使用脚本判定、地板颜色和音效，不生成实体 TNT。

## 构建、测试与部署

```sh
cd addons/bomber
npm ci
npm run build
npm test
./deploy.sh
```

默认部署到 `ubuntu@jinjiazh.com`，可用 `BOMBER_HOST` 覆盖。部署会短暂重启 Bedrock，把根目录和世界目录的行为包列表切换为仅启用 bomber。旧 lodestone 行为包、世界和探险存档保留；不会同时运行旧探险的传送逻辑。部署前自动备份启用列表和已有 bomber 包，复制失败自动恢复。

测试覆盖爆炸规则、对称布局、连锁、出局、重开、自动补位、重生入场和独立入口。真实客户端操作手感与联机显示仍需游戏内验收。

炸弹使用脚本十字判定。不会放置原生 TNT 或红石供电块，并取消原生爆炸，保护竞技场墙壁与地板。木箱沿用原版玩法的脚本破坏与掉落规则。
